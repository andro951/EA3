# Continuity and memory review

Open Memories & relationships, then Find important memories. This is an explicit additional request to the selected text provider; it can use provider quota or cost money according to that provider's plan. Nothing runs automatically in the background. Manual memory entry works without a provider.

The review includes up to twelve recent complete narrative turns within a disclosed character budget. Older or oversized content is not silently rewritten; omitted earlier-turn count is shown before review. Existing memory and allowed character identities are supplied. Every proposed fact must include a verbatim quote from the exact source turn. Unknown sources, invented quotations, invalid subjects and mature-only suggestions in an SFW review are rejected. Existing duplicate facts are skipped.

A matching quote proves that the words appeared, not that the interpretation is correct. Review the proposal, including whether a speaker was claiming something or describing a hypothetical. Keep or dismiss each proposal. Keeping a proposal is a canonical state event; it does not alter money, inventory, party, equipment or location. Rewinding past that point removes its state change. No alternate player timeline is kept.

If the adventure changes during review, the result is stale and not inserted. Failed or uncertain requests are retained in the local Workbench; they are not automatically retried. The review is not a replacement for full automatic long-context reconciliation, and live model accuracy remains dependent on the selected provider.
